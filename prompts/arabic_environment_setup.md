# تعليمات تجهيز الكمبيوتر بالعربي

هذه التعليمات قبل بدء Claude Code.

الهدف هو تجهيز الكمبيوتر بطريقة آمنة ومنظمة.

## القاعدة المهمة

اشتغل فقط داخل مجلد المشروع.

لا تشغل Claude Code من سطح المكتب Desktop.

لا تشغله من Downloads.

لا تشغله من مجلد فيه ملفات شخصية.

## 1. البرامج المطلوبة

تحتاج هذه البرامج:

1. Python
2. Git
3. Visual Studio Code
4. Claude Code

إذا كانت البرامج موجودة عندك، لا تحتاج تثبيتها مرة ثانية.

## 2. إنشاء مجلد المشروع

افتح المكان الذي تريد حفظ المشروع فيه.

أنشئ مجلدا جديدا اسمه:

```text
parkinsons_voice_project
```

افتح هذا المجلد فقط.

## 3. فتح المجلد في VS Code

افتح Visual Studio Code.

اختر:

```text
File > Open Folder
```

ثم اختر مجلد:

```text
parkinsons_voice_project
```

## 4. فتح Terminal داخل VS Code

من داخل VS Code اختر:

```text
Terminal > New Terminal
```

تأكد أن Terminal مفتوح داخل مجلد المشروع.

يجب أن ترى اسم المجلد في السطر، أو يكون المسار منتهيا بهذا الاسم:

```text
parkinsons_voice_project
```

إذا لم تكن داخل هذا المجلد، لا تكمل.

## 5. التأكد من Python

اكتب هذا الأمر في Terminal:

```bash
python --version
```

إذا لم يعمل، جرب:

```bash
python3 --version
```

إذا ظهر رقم مثل هذا، فالأمر جيد:

```text
Python 3.11.x
```

أو:

```text
Python 3.12.x
```

إذا لم يظهر رقم Python، انسخ الرسالة وأرسلها إلى ChatGPT.

## 6. التأكد من Git

اكتب:

```bash
git --version
```

إذا ظهر رقم إصدار Git، فالأمر جيد.

إذا لم يعمل، انسخ الرسالة وأرسلها إلى ChatGPT.

## 7. إنشاء virtual environment

مهم جدا: لا تثبت مكتبات Python على الكمبيوتر كله.

يجب إنشاء بيئة خاصة داخل المشروع.

اكتب داخل Terminal:

```bash
python -m venv .venv
```

إذا لم يعمل، جرب:

```bash
python3 -m venv .venv
```

بعدها يجب أن يظهر مجلد اسمه:

```text
.venv
```

داخل المشروع.

## 8. تشغيل virtual environment

إذا كان الكمبيوتر Windows، اكتب:

```bash
.venv\Scripts\activate
```

إذا كان الكمبيوتر macOS أو Linux، اكتب:

```bash
source .venv/bin/activate
```

بعد التشغيل، يجب أن ترى شيئا مثل هذا في بداية السطر:

```text
(.venv)
```

إذا رأيت `(.venv)` فهذا جيد.

إذا لم يظهر، انسخ الرسالة وأرسلها إلى ChatGPT.

## 9. التأكد أن pip داخل البيئة

اكتب:

```bash
python -m pip --version
```

المهم أن يظهر المسار وفيه:

```text
.venv
```

إذا لم يظهر `.venv`، لا تكمل. أرسل الرسالة إلى ChatGPT.

## 10. فتح Claude Code داخل مجلد المشروع

بعد أن تتأكد أنك داخل مجلد المشروع وأن `.venv` تعمل، افتح Claude Code من نفس Terminal أو حسب الطريقة التي تستخدمها.

مهم:

يجب أن يكون Claude Code مفتوحا داخل هذا المجلد فقط:

```text
parkinsons_voice_project
```

## 11. أول رسالة ترسلها إلى Claude Code

انسخ برومبت Claude Code kickoff كامل وأرسله إلى Claude Code.

لا تعطه أوامر صغيرة.

اتركه يعمل في auto mode.

عندما ينتهي، انسخ ملخصه النهائي وأرسله إلى ChatGPT العربي.

## 12. أين نضع قاعدة البيانات؟

لاحقا، عندما تحصل على بيانات MDVR KCL، ضعها داخل مجلد المشروع في مكان مثل:

```text
data/raw/mdvr_kcl
```

لا تغير أسماء كثيرة بنفسك إلا إذا قال Claude Code ذلك.

## 13. إذا ظهر خطأ

لا تحاول إصلاحه عشوائيا.

انسخ الخطأ كاملا وأرسله إلى ChatGPT العربي.

قل له:

```text
هذا الخطأ ظهر لي. ماذا أفعل؟
```

## 14. تذكير مهم

Claude Code هو الذي يبرمج.

أنت فقط:

1. تشغل الأوامر المطلوبة.
2. تنسخ ملخص Claude Code إلى ChatGPT.
3. تنفذ التعليمات البسيطة.
4. تسأل حسين فقط عندما يقول ChatGPT إن القرار كبير.
