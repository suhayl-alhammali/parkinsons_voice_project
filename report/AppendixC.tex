\chapter{Software Repository and Reproduction Guide}
\label{app:repro}

All code, configuration, tests, generated reports, figures, and
documentation of this project are version-controlled in a public
repository:

\begin{center}
\url{https://github.com/suhayl-alhammali/parkinsons_voice_project}
\end{center}

The audio corpora are \emph{not} redistributed (they remain under
their own licences); the repository contains download instructions
instead. Every quantitative result in this report is regenerated by
the scripts below.

\section{Reproduction Sequence}

All commands are executed in the project folder with the project's
Python virtual environment active. Approximate runtimes refer to an
ordinary laptop.

\begin{enumerate}
  \item \texttt{pip install -r requirements.txt} --- install
        dependencies (once).
  \item Place the extracted MDVR-KCL corpus under
        \texttt{data/raw/mdvr\_kcl/} (download instructions in that
        folder).
  \item \texttt{python tests/test\_pipeline.py} --- pipeline self-test
        on synthetic audio (seconds).
  \item \texttt{python scripts/inspect\_dataset.py} --- dataset
        inspection report (seconds).
  \item \texttt{python scripts/build\_features.py} --- baseline
        43-feature table ($\sim$12 min).
  \item \texttt{python scripts/validate\_features.py} --- feature
        quality report (seconds).
  \item \texttt{python scripts/train\_models.py} --- baseline
        evaluation of Table~4.1 ($\sim$2 min).
  \item \texttt{python scripts/build\_segment\_features.py} ---
        chunk-level 74-feature table ($\sim$32 min).
  \item \texttt{python scripts/run\_experiments.py} --- the
        19-configuration study of Table~4.3 ($\sim$30 min).
  \item \texttt{python scripts/train\_final\_model.py} --- final model,
        its report, and artefacts ($\sim$1 min).
  \item \texttt{python scripts/make\_figures.py} --- all result
        figures, including the leakage comparison ($\sim$2 min).
  \item External corpus inspection and frozen-model evaluation
        ($\sim$75 min; requires the Italian corpus under
        \texttt{data/raw/italian\_pvs/}):\\
        \texttt{python scripts/inspect\_italian\_dataset.py}\\
        \texttt{python scripts/evaluate\_external.py}
  \item \texttt{streamlit run app.py} or
        \texttt{python scripts/predict\_file.py <file.wav>} --- the
        prototype.
\end{enumerate}

Long extraction stages cache per-file results
(\texttt{data/processed/*\_cache/}) and resume automatically if
interrupted. Fixed random seeds make every training and evaluation
run deterministic.

\section{Artefacts}

The trained model is stored as \texttt{models/model.joblib} beside its
pipeline contract \texttt{models/pipeline\_config.json}, which records
every preprocessing, segmentation, and feature setting together with
the complete ordered feature list; the prediction path refuses to run
if this contract does not match the code (Section~3.2). Out-of-fold
prediction tables (\texttt{data/processed/*.csv}) preserve, for every
recording, its subject, task, fold, true label, and score, allowing
independent recomputation of every metric in this report.
